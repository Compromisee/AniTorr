3CLI

Launch with no flags and a pastel mode picker appears. Pick anime / manga / settings and the rest is keyboard-driven.

~ / anitorr

4Anime flow

Query → metadata + variants → 8 trackers in parallel → relevance gate → NN rank → table → pick row → qBittorrent metadata fetch → file table → select files → send to client. Every step shown live below.

~ / anitorr — anime

Relevance gate

Drops results whose title shares no token with your query AND contains no Latin/CJK characters — catches Russian / Arabic / unrelated-language releases that flood Nyaa.

Neural fallback

If the top-10 NN-ranked results have <30% token overlap with your query, ANITorr automatically falls back to seeder-sort. You'll see a yellow warning in the CLI when it triggers.

5Manga flow

Same shape as anime: query → series picker → chapter table → format → autocrop? → background download. Outputs CBZ / ZIP / EPUB / PDF with proper metadata.

~ / anitorr — manga

EPUB metadata

Apple Books, Calibre, KOReader and Kindle all read these fields:

  • dc:identifier — UUID, unique per export
  • dc:title / creator / language / date
  • rendition:layout: pre-paginated — Apple Books spread mode
  • rendition:orientation: portrait
  • ibooks:specified-fonts: true
  • calibre:series + calibre:series_index
  • Cover with properties="cover-image"
  • RTL page progression by default; LTR for webtoons

10How the ranker learns

Every time you pick a result, ANITorr nudges its weights toward the picked features and away from the others. Watch the math happen below.

~ / ranker

The model

  • seeders — log-scaled health
  • resolution — bucketed 2160/1080/720/480
  • group_trust — boolean trust list
  • size_efficiency — smaller @ same res = better
  • prompt_match — token overlap vs query
  • codec — x265 / AV1 weighted higher
  • batch — season pack flag
  • bias

The loop

  1. You search → backend fans out to every source
  2. Relevance gate drops unrelated-language releases
  3. Ranker scores every row → sorts descending
  4. NN quality is sampled. If <30%, fall back to seeder sort
  5. You click one → label=1 for that row, 0 for others
  6. SGD step nudges weights by learning_rate
  7. Weights + last 500 picks persist to data/nn_cache.json
  8. Next search uses the updated weights — your taste compounds
